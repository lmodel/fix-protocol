# Glossary

* [Extension pack](extension-pack.md) - An extension pack: the numbered unit in which FIX Latest changes; each record names the packs that added, last changed and deprecated it.
* [Record identifier](record-identifier.md) - A record's `id`: a prefix for its kind and FIX's own number or name, such as `fix_field:55` or `fix_category:Allocation`, since FIX numbers each kind on its own.
* [Departure](departure.md) - A departure: a place where FIX Latest's own data breaks a rule it otherwise keeps; the catalogue keeps it as FIX wrote it and `tests/upstream_departures.yaml` names it.

# Policies

* [AI covenant](ai-covenant.md) - The rules for AI-assisted work in this repository: the contributor owns every contribution, a record says what FIX's file says, and FIX's words stay out.
* [License and attribution](license-and-attribution.md) - NOTICE: the project is under the Apache License 2.0, FIX's file stays under the FIX Trading Community's terms, and the records hold no text of FIX's; nothing comes from fixtrading.org.
* [Security policy](security-policy.md) - SECURITY.md: report a vulnerability by private vulnerability reporting; it says what executes here, from the tests to the scheduled librarian, and what holds each.

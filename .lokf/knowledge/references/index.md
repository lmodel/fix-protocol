# References

* [FIX Latest](fix-latest.md) - FIX Latest, the FIX Trading Community's current FIX application layer, which changes by extension packs and which the schema models at extension pack 312 from its Orchestra file.
* [The orchestrations repository](orchestrations-repository.md) - FIXTradingCommunity/orchestrations on GitHub, licensed under the Apache License 2.0, which publishes FIX Latest as `FIX Standard/OrchestraFIXLatest.xml` and which the upstream watch compares each week.
* [FIX Orchestra 1.0](orchestra-1-0.md) - Orchestra 1.0, the FIX Trading Community's format for machine-readable rules of engagement, which FIX Latest's file follows and whose names the `fixr:` mappings use.
